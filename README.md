# Abigail-Arevalo_Portfolio
Abigail-Arevalo_Portfolio
TThis is my personal portfolio website, built with HTML and CSS. It introduces me as a Graphic Information Technology student at Arizona State University, shares my skills and interests, and showcases my web design projects, including T.Access, Kintide, Indie Film Collective, and Harborview Farmers Market. The site uses a mobile-first design, a flex navigation, a grid layout, and a media query so the layout changes between phones and larger screens. It also includes accessibility features such as alt text on images, a logical heading order, descriptive link text, and readable color contrast.
AI was used to help refine the written content about me to provide clarity, better word flow, and grammar. None of the following HTML or CSS was written by AI or generated with AI, all CSS and HTML code was written by me, Abigail Arevalo
